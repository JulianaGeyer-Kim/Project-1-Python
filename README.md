# Project-1-Python

A portfolio of Python programs and exercises from my introductory Python course. Each notebook was written in Google Colab and covers a core programming concept.

## Skills Demonstrated

- Variables, data types, and user input
- Conditionals (`if` / `else` / `elif`)
- `for` and `while` loops
- Lists and dictionaries
- Error handling with `try` / `except`
- Data analysis with Pandas
- Basic financial and date calculations
- Problem solving and program design

## How to Run

These notebooks were created in Google Colab.

1. Open any `.ipynb` file in this repository on GitHub.
2. Click the **Open in Colab** badge at the top of the notebook, or download the file and upload it to [Google Colab](https://colab.research.google.com/).
3. Run the cells in order.

You can also run them locally with Jupyter Notebook:

```bash
pip install notebook
jupyter notebook
```

For `PandasAssignment.ipynb`, you may also need:

```bash
pip install pandas
```
